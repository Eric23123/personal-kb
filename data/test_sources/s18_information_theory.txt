# Information Theory — Entropy, Capacity, and Coding

## Shannon Entropy

For a discrete random variable X with distribution p(x), the entropy (in bits
if log base 2, nats if natural log) is:

    H(X) = -Σ_{x∈X} p(x) log₂ p(x)

Entropy quantifies the average uncertainty or information content. Properties:
- 0 ≤ H(X) ≤ log₂|X|, with H(X) = 0 iff X is deterministic
- H(X) = log₂|X| iff X is uniform
- H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)  (chain rule)

## KL Divergence and Mutual Information

The Kullback-Leibler divergence measures the "distance" between distributions:

    D_KL(p || q) = Σ_x p(x) log₂(p(x) / q(x))

D_KL(p || q) ≥ 0 with equality iff p = q (Gibbs' inequality). It is NOT symmetric:
D_KL(p || q) ≠ D_KL(q || p). The KL divergence is central to variational inference
where ELBO = log p(D) - D_KL(q(θ) || p(θ|D)) — see s06.

Mutual information quantifies the dependence between X and Y:

    I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = D_KL(p(x,y) || p(x)p(y))

Properties: I(X; Y) ≥ 0, I(X; Y) = 0 iff X ⟂ Y. The data processing inequality:
if X → Y → Z is a Markov chain, then I(X; Z) ≤ I(X; Y).

## Channel Capacity

For a discrete memoryless channel p(y|x), the capacity is:

    C = max_{p(x)} I(X; Y)   [bits per channel use]

Shannon's Noisy Channel Coding Theorem: for any rate R < C, there exists a code
achieving arbitrarily low error probability. Conversely, if R > C, reliable
communication is impossible.

**AWGN Channel:** y = x + n, n ~ N(0, σ²), with power constraint E[X²] ≤ P:

    C = (1/2) log₂(1 + P/σ²) = (1/2) log₂(1 + SNR)   [bits per channel use]

This is the Shannon-Hartley theorem. Bandwidth-limited capacity:
C = B log₂(1 + SNR) bits/second, where B is bandwidth in Hz.

## Source Coding Theorem

For a discrete source X with entropy H(X), the minimum average codeword length
L̄ satisfies: H(X) ≤ L̄ < H(X) + 1. Huffman coding achieves the optimal prefix
code for known distributions. Arithmetic coding approaches the entropy bound
arbitrarily closely for long sequences without the integer-length constraint.

For lossy compression of a Gaussian source X ~ N(0, σ²) with squared-error
distortion D, the rate-distortion function is:

    R(D) = max(0, (1/2) log₂(σ² / D))   [bits per sample]

## Differential Entropy

For a continuous random variable with density f(x), the differential entropy is:

    h(X) = -∫ f(x) log f(x) dx

Unlike discrete entropy, h(X) can be negative. The Gaussian distribution
maximizes differential entropy for a given variance: h(X) ≤ (1/2) log₂(2πeσ²).
