# Personal KB 新手使用指南

## 这是什么

Personal KB 是你的本地知识库。你选择的文件夹就是知识库本体：可以直接用资源管理器整理，也可以作为 Obsidian 仓库打开。应用只会在其中建立隐藏的 `.personal-kb` 文件夹，用来保存检索索引、提取文本和回收站。

## 第一次使用

1. 打开 Personal KB，进入“设置”。
2. 选择“默认知识库目录”。建议新建一个空文件夹，例如 `D:\资源库`。
3. 填入并保存 DashScope API Key。它用于建立语义检索索引。
4. 填入并保存 DeepSeek API Key。它用于把检索到的原文整理成自然语言回答。
5. 回到“资料库”。

密钥保存在 Windows 凭据管理器，不会写入你的知识库文件夹。

## 添加资料

在“资料库”中，把单个文件或文件夹拖进大方框，也可以点击选择文件或选择文件夹。

支持：PDF、文本与 Markdown、图片、音频，以及包含这些文件的文件夹。导入后，原文件会复制到知识库的 `收件箱` 中，随后自动提取文本并建立索引。

导入完成后，进入“资源管理”。状态含义：

- 已处理：资料已可搜索。
- 待处理：资料已经进入知识库，但尚未处理。选中后点击“处理并索引”。
- 待同步：你在资源管理器或 Obsidian 中改动过原文件。确认内容后重新处理即可。
- 处理失败：通常是网络、密钥或本地服务刚启动造成。确认设置后选中该文件，再点击“处理并索引”。

## 搜索资料

进入“搜索”，用完整的问题描述你的需求，例如：

- `消元法如何把 Ax=b 化为 Ux=c？`
- `这份讲义如何解释线性方程组的几何意义？`

系统会先从你的资料中找原文，再由 DeepSeek 组织为中文回答，并在末尾列出来源。若只显示简短原文摘要，通常是 DeepSeek 密钥尚未设置或暂时无法连接。

## 管理知识库

“资源管理”以文件夹为主组织资料。你可以按文件夹筛选、按名称或时间排序，并选择文件执行以下操作：

- 处理并索引：让新增或改过的文件可以搜索。
- 创建关联笔记：在 `notes` 文件夹中建立一份 Obsidian Markdown 笔记。
- 建立知识链接：选择至少两份资料，建立“相关知识”“同一课堂”或“前后关系”。前后关系需要明确哪份资料在前、哪份在后。
- 移入回收站：把真实文件移动到 `.personal-kb/recycle`，不会立刻永久删除。

建议在资源管理器或 Obsidian 中按主题建立文件夹，例如 `数学/线性代数`、`工作/项目资料`。应用会自动识别这些层级。

知识链接不会为每份资料自动创建笔记，也不会修改你已有的 Obsidian 笔记。所有链接集中保存在 `.personal-kb/relations.json`，后续“知识网络”页面会使用这份数据展示和编辑资料之间的连线。

## 与 Obsidian 一起使用

在 Obsidian 中选择“打开本地仓库文件夹”，并选中你的知识库目录。之后：

- 你可以正常创建、编辑和移动 Markdown 笔记。
- 新增或修改资料后，回到 Personal KB 的资源管理页刷新并重新处理。
- 不要手动修改 `.personal-kb` 文件夹；它是应用维护的索引数据。

## 常见问题

**刚导入就显示待处理或处理失败**

等待几秒后在资源管理页点击刷新，选中文件后点击“处理并索引”。确认 DashScope API Key 已保存。

**搜索没有结果**

先确认资料状态为“已处理”，再用更具体的描述搜索。扫描版 PDF 的识别结果也会影响搜索质量。

**能否直接删除文件？**

可以在资源管理器中删除，但应用下次刷新会把它标记为缺失。推荐通过应用的“移入回收站”操作，以便恢复。
